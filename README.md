# 🌿 Solstice

> Where nature meets your feelings

A mood-based Spotify playlist recommender built with React + Firebase.

## Setup & Deploy

### 1. Install dependencies
```bash
npm install
```

### 2. Run locally
```bash
npm start
```

### 3. Deploy to GitHub Pages
```bash
npm run deploy
```

Your site will be live at:
**https://nikhilant15-lgtm.github.io/solstice**

## Tech Stack
- React 18
- Firebase Auth (Email + Google)
- Firestore Database
- GitHub Pages hosting
